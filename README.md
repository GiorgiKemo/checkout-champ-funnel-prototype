# CalmFuel conversion funnel prototype

This is an independent portfolio demo inspired by the type of presell, offer, order-bump, and checkout flow a team might implement inside a funnel platform such as Checkout Champ. It is **not** a claim of prior Checkout Champ production experience and it does not process real payments.

## Included

- Conversion-focused presell page with proof, benefits, FAQ, and clear CTA
- Offer card with order-bump state and live total calculation
- Responsive checkout modal with client-side validation
- Success state that demonstrates the handoff to a payment provider
- Mobile layout and keyboard-accessible modal controls

## Run locally

From this directory:

```powershell
python -m http.server 4173
```

Then open `http://127.0.0.1:4173`.
